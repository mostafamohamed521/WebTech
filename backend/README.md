# WEBTECH Backend — سجل عمليات Git

سجل بكل الملفات اللي اتعملها في الجزء ده وأمر الـ git المستخدم لكل ملف:

```bash
git add backend/apps/authentication/__init__.py
git commit -m "apps/authentication/__init__.py: تهيئة تطبيق authentication"
```

```bash
git add backend/apps/authentication/apps.py
git commit -m "apps/authentication/apps.py: إعدادات تطبيق authentication (المصادقة وتسجيل الدخول وإدارة التوكنز)"
```

```bash

git commit -m "apps/authentication/models.py: تعريف نماذج المصادقة وتسجيل الدخول وإدارة التوكنز"
```
